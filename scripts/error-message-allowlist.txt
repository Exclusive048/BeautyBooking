# ERROR-MESSAGE-LANG allowlist (ERR-LOCALIZATION-01, 2026-08-04)
# ─────────────────────────────────────────────────────────────────
# Сообщения об ошибках, которым разрешено НЕ содержать кириллицу.
#
# СПИСОК НАМЕРЕННО ПУСТ. Свип ERR-LOCALIZATION-01 перевёл все 581 сайт
# (491 прямых + 90 через объект-результат) и не нашёл ни одной строки,
# которой перевод бы навредил — включая конфигурационные, где технический
# токен просто оставлен внутри русской фразы:
#
#   "AUTH_JWT_SECRET is not configured" → "Не настроен AUTH_JWT_SECRET."
#
# Диагностическая ценность в логах при этом сохраняется (русский в логах —
# норма проекта), а пользователь, если строка до него доедет, видит русский
# текст, а не английский.
#
# ── Когда сюда можно добавлять ──────────────────────────────────────
# Только если сообщение доказуемо НЕ покидает сервер к пользователю
# (уходит исключительно в лог / внутренний канал) И перевод реально
# ухудшил бы разбор инцидента. Строка добавляется ТОЧНЫМ текстом плюс
# комментарий с причиной над ней.
#
# Паттернов нет намеренно: точная строка не расширяет разрешение молча.
# **Пустой allowlist лучше раздутого** — сомнение трактуется в пользу
# перевода. Появление здесь первой строки — повод для вопроса на ревью,
# а не рутина.
#
# Формат: одна строка на запись, без кавычек. Пустые строки и # игнорируются.
