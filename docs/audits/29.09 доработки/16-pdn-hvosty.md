## Решения владельца

1. **(юрист)** Реклама ли уведомление «горящее окошко со скидкой» мастера, на которого человек сам подписался (38-ФЗ ст. 3, ст. 18 ч. 1 — реклама по сетям электросвязи только с предварительного согласия)?
   - **А** — подписка на мастера и есть согласие. Общий `MARKETING` не нужен, в реестре пусто. Тогда надо поправить тексты переключателя и `/consent` §7: «акции мастеров, на которых вы подписаны, приходят по подписке».
   - **Б** — нужен и `MARKETING`: в реестр идут оба типа.
   - **В** — нужен только для скидочных: в реестре `HOT_SLOT_AVAILABLE`, а `SLOT_FREED` (без скидки, информационное) идёт по подписке.
   **Рекомендация: В.** Наши же документы называют скидки акциями, а «окошко освободилось» — ответ на явный запрос человека. Последствия: А — ничего не отключается, правятся только тексты; Б и В — подписчики без согласия перестают получать соответствующие пуши, пока не отметят чекбокс (шаг Б4).
2. **Какая строка согласия считается?** Любая активная `MARKETING` или только текущей версии документа (так в BACKLOG)? **Рекомендация: любая активная.** Иначе поднятие версии документа молча выключит акции всем, а перезапрос согласия при входе — отдельная задача.
3. **Уже подписанные без согласия** в момент включения: молча перестать слать или один раз показать в кабинете плашку «Разрешите акции мастеров»? **Рекомендация: плашка** на странице уведомлений клиента, без рассылки.
4. **Пороги аномалий (стартовые, режим наблюдения две недели):** ADMIN — больше 1 000 строк или 60 событий за час (≈20 страниц списка по 50); MASTER / STUDIO — больше 3 000 строк за час. Исключений для поддержки не заводить, частоту держит окно тишины 6 ч. Да / свои числа?

## Готово, когда
- После удаления фото любым из четырёх путей у ассета нет эмбеддинга и `visual*` пустые. Фото, удалённое во время индексации, эмбеддинг не получает. Исторические строки уходят за один-два часовых прохода.
- У каждого `NotificationType` есть классификация; тип из реестра без активного `MARKETING` не создаётся ни в одном канале; реестр наполнен по ответу на вопрос 1.
- Открытие страниц «Клиенты» мастера и студии пишет строку `PdAccessLog`.
- Превышение порога видно в логе (режим наблюдения), а после включения — в Telegram и GlitchTip, без IP и id человека.
